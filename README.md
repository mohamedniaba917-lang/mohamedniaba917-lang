## 🧠 What I learned building them

- **Game loops and timing** — `requestAnimationFrame` with delta time, so games run at the same speed on any device
- **Physics** — gravity, launch velocity, bounces and energy loss (Hoops Rush)
- **Collision detection** — circle-vs-circle, circle-vs-rectangle, line segments and sub-stepping so fast objects can't pass through walls
- **Game AI** — bots that loot, move to the safe zone, check line of sight and choose who to fight (Last Zone)
- **State machines** — controlling the flow of each kick: aim → power → flight → result (Penalty Kings)
- **Procedural generation** — a new random map every match
- **Touch controls** — virtual joysticks and tap input so every game works on a phone
- **Sound in code** — sound effects generated with the Web Audio API, no audio files
